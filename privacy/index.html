Still Privacy Policy

Effective August 15, 2026 · Last updated August 15, 2026

Still is designed to review selected file information privately on your device. This policy explains the data practices of the current release.

Information handled by the app

When you explicitly choose files or folders through Apple’s document picker, Still reads metadata needed for the review experience. This may include an item’s name, type, size, modification date, directory status, and whether an iCloud item has a local copy.

Still does not read or upload the contents of selected files.

How information is used

The metadata is used only to display, search, filter, sort, and review the items you selected.

Storage and retention

Selected metadata, a system file reference, and review progress are saved in the app’s private storage so your library can continue after a relaunch. Still excludes this review library from device backups, and the information is not stored on our servers. Still balances temporary security-scoped access whenever it checks a saved reference, and access may become unavailable if a file moves or a provider changes permission.

Delete Still from your iPhone to remove those saved references and review records. Deleting Still does not delete the original files.

External file changes

Still does not delete, move, rename, or otherwise modify files selected from iCloud Drive or another external document provider. Review decisions such as Keep, Later, and Set Aside do not alter the original item.

Data collection

The current version of Still:

  • Does not require an account.
  • Does not include advertising.
  • Does not include analytics or tracking SDKs.
  • Does not sell or share personal information.
  • Does not transmit selected file metadata off your device.

Children’s privacy

Still does not knowingly collect personal information from children or any other user.

Website hosting

This website is hosted by GitHub Pages. GitHub may process standard request information under its own privacy terms. Still does not add website analytics, advertising, tracking pixels, or contact forms.

Developer and contact

Still is provided by Anul Jain, based in India. For privacy questions, email support@wristaudiooffline.app.

Changes to this policy

If Still’s data practices change, this policy and the App Store privacy disclosures will be updated before the affected version is released.
