Foldrobe Privacy Policy

Effective August 23, 2026 · Last updated August 23, 2026

Foldrobe is designed to organize allowed-folder information privately on your device. This policy explains the data practices of the current release.

Information handled by the app

When you explicitly choose a folder through Apple’s document picker, Foldrobe recursively reads metadata for accessible files inside that folder. This may include an item’s name, type, size, modification date, and whether an iCloud item has a local copy.

Foldrobe reads image bytes to render previews. When you request copy, move, rename, or deletion, Apple’s coordinated file APIs perform that operation locally on the selected files. Foldrobe does not upload file contents or indexed metadata.

How information is used

Metadata is used only to index, display, search, filter, sort, and produce storage analytics for files inside folders you allowed.

Storage and retention

Indexed metadata and secure system file references are saved in the app’s private storage so Foldrobe can watch authorized folders while active and rescan after a relaunch. Foldrobe excludes this file index from device backups, and the information is not stored on our servers. Foldrobe balances temporary security-scoped access whenever it checks a saved reference, and access may become unavailable if a file moves or a provider changes permission.

Delete Foldrobe from your iPhone to remove its saved references and index. Deleting the app itself does not delete the original files.

File operations

Foldrobe copies, moves, cuts/pastes, or renames files only after you initiate the action and choose a destination or new name. It never overwrites a same-named destination. Deletion requires explicit confirmation and removes files from their original folder. Whether recovery is available depends on iCloud Drive or the external provider.

Data collection

The current version of Foldrobe:

  • Does not require an account.
  • Does not include advertising.
  • Does not include analytics or tracking SDKs.
  • Does not sell or share personal information.
  • Does not transmit selected file metadata off your device.

Children’s privacy

Foldrobe does not knowingly collect personal information from children or any other user.

Website hosting

This website is hosted by GitHub Pages. GitHub may process standard request information under its own privacy terms. Foldrobe does not add website analytics, advertising, tracking pixels, or contact forms.

Developer and contact

Foldrobe is provided by Anul Jain, based in India. For privacy questions, email support@wristaudiooffline.app.

Changes to this policy

If Foldrobe’s data practices change, this policy and the App Store privacy disclosures will be updated before the affected version is released.
