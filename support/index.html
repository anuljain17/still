Still Support

A calm companion for reviewing file details on iPhone.

Getting started

  1. Open Browse and tap Add References.
  2. Choose files or folders in Apple’s document picker.
  3. Use Review for one-at-a-time decisions.
  4. Use Search to narrow the view with filters.

Current release

  • Selected references and review progress are remembered between launches in Still’s private app storage.
  • Still does not delete or move files selected from iCloud Drive or another document provider.
  • Keep, Later, and Set Aside are review decisions. They do not modify the original file.
  • Use Apple Files or the source provider’s app to complete a move or deletion.

Frequently asked questions

Did Still delete my file?

No. The current release does not delete or move files selected through Apple’s document picker.

Why does Still ask me to select an item again?

A file may have moved, been removed, or its provider permission is no longer available. Choose the item again in Apple’s picker to restore access. Still does not change the file.

How do I remove saved references?

Delete Still from your iPhone to remove its private review library. Your original files remain untouched.

Does Still upload my file details?

No. Selected metadata is processed locally on your iPhone.

Does Still read my file contents?

No. Still reads only the metadata needed for review, such as name, size, type, and modification date.

Can I undo a review choice?

Yes. Use Undo during the focused review flow.

Accessibility

Still supports VoiceOver, Dynamic Type, dark mode, Reduce Motion, and Reduce Transparency.
