Foldrobe Support

A digital wardrobe for organizing files on iPhone.

Getting started

  1. Open Browse and tap Add Folder.
  2. Choose one or more folders in Apple’s secure document picker.
  3. Use Analytics to inspect large, old, and possibly duplicated files.
  4. Use Search & Manage to select files for copy, move, cut/paste, rename, or deletion.

Current release

  • Allowed-folder references and indexed metadata are remembered in Foldrobe’s private app storage.
  • Foldrobe watches authorized folders while active and rescans whenever it returns to the foreground.
  • Images are read locally to render previews and are not uploaded.
  • Copy, move, cut/paste, and rename never overwrite an existing destination file.
  • Deletion requires an explicit confirmation and removes files from their original folder.

Frequently asked questions

How do bulk filename operations work?

Enter a filename phrase in Search, then choose Delete all filenames containing that phrase. Foldrobe shows the number of matching files and asks you to confirm before deletion.

How do I copy, move, cut, paste, or rename files?

In Search & Manage, tap Select and choose one or more indexed files. Open File actions to copy or move them into an authorized folder, or Cut them and use Paste. Rename is available when exactly one file is selected.

Why does Foldrobe ask me to select a folder again?

The folder may have moved, been removed, or its provider permission is no longer available. Choose the folder again in Apple’s picker to restore access.

How do I remove the saved index?

Delete Foldrobe from your iPhone to remove its private file index. Deleting the app does not delete original files.

Does Foldrobe upload my file details?

No. Selected metadata is processed locally on your iPhone.

Why is an image preview unavailable?

The image may be larger than the preview safety limit, stored only in the cloud, unsupported, or no longer covered by the saved provider permission. Refresh the folder and try again.

Accessibility
